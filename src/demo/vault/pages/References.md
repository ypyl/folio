# References

A reference is how one page names another. Folio has one reference form with two
spellings: a word form, a `#` followed by a name that is a single word, and a
bracketed form, two opening brackets around a name of any shape. Both produce the
same badge and the same link.

> Demo guide. #Welcome has the table of contents.

## Both spellings

- #Inbox is a word reference to the Inbox page.
- #[[Reading list]] is a bracketed reference to a name with a space.
- #references is the same page as #References: names ignore case.
- #References points back here; a page never backlinks itself.

## A reference to a page that does not exist

#missing-topic names no page in this vault. The reference is still valid: click
it and a blank page opens, and the page is created only when you save something
into it. This is the one deliberately missing name in the demo.

## What clicking does

Click a badge to open its target. Put the caret inside a badge and press
`Ctrl/Cmd+Enter` to do the same from the keyboard. Start typing `#` in a page and
the completion list offers the vault's page names, and the completion after two
opening brackets offers the bracketed form.

## Code stays literal

A reference written inside a code span is not a badge: `#References` stays text.
