# Presenting

Any page can become a deck. Right-click the page's row in Files and choose
**Present**. The app reads the live editor document, so unsaved edits present too.

> Demo guide. #Welcome has the table of contents.

## Slides are separated by a rule

A line with three dashes starts a new slide. Nothing else changes: the same
Markdown you edit is what the deck shows.

---

## A second slide

Slides render headings, lists, tables, images, and code. This page has three.

---

## A third slide

Press Escape or use the close control to return to the page exactly as it was.
Presenting writes nothing to the vault.
