# Welcome to the Folio demo

This is a **virtual vault**. It holds the same files a real Folio vault holds —
pages under `pages/`, days under `journals/`, boards under `boards/`, files under
`assets/`, and the app's own notes in `.folio/` — but it lives in this tab
instead of on your disk. Every feature is real. Edit anything: your changes last
for the session. Closing the demo or reloading the tab starts it fresh, and
nothing is ever written to your computer.

## Try it in a minute

- Open #References and click one of its reference badges.
- Press `Ctrl/Cmd+P` and search for `page: reminder`.
- Open the board from #Boards and draw on it.
- Click **Today** in the status bar: the demo's reminders land in today's note.

## How the demo is organized

| Path        | What it holds                |
| ----------- | ---------------------------- |
| `pages/`    | one Markdown file per page   |
| `journals/` | one Markdown file per day    |
| `boards/`   | the `.excalidraw` whiteboard |
| `assets/`   | an image and a text file     |
| `.folio/`   | pins and reminder rules      |

The sidebar lists all of it. The calendar marks the days that have notes. The
right panel shows this page's headings and its links.
