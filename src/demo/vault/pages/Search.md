# Search

Press `Ctrl/Cmd+P` or `Ctrl/Cmd+K`, or click the magnifier in the left rail. The
search looks at pages and journal days by content, and at boards and assets by
name.

> Demo guide. #Welcome has the table of contents.

## Try these

| Query                | Leads with                                  |
| -------------------- | ------------------------------------------- |
| `page: reminder`     | pages whose text matches "reminder"         |
| `journal: {{today}}` | the journal day for today                   |
| `board: folio`       | the demo board                              |
| `assets: flow`       | the SVG in the assets folder                |
| `title: welcome`     | matches in a title or name, under **Names** |

Every term must match. A term of three or more characters matches literally or
fuzzily; a shorter term matches a whole word only. An operator reorders the
results and never hides one, and the first operator in a query wins.

## See the whole result set

The dropdown shows the first few matches. Choose the see-all row to open the full
results view. Closing the view returns to the page you were reading.

## Search follows the vault

The index is rebuilt as you save. Add a word to #Inbox, wait for the save, and
search for it: it appears without a reload. The demo's search is over the demo's
own files.
