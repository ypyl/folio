# Boards

A board is an `.excalidraw` file under `boards/`. It is a vault file, not a page:
it has no backlinks of its own and no Contents. A page names it with a hash, a
bang, and the board's name.

> Demo guide. #Welcome has the table of contents.

## Open the demo board

#![[How Folio works]] opens the board in the main pane. Draw something and it
saves a second later, like a page. A board with no elements shows a note naming
the token that points at it.

## What a board is for

Sketch the shape of a problem, keep a diagram next to the pages that cite it, and
let the board stay a single file in the folder. The Boards section of Files lists
the vault's boards, and a board's own panel lists the pages that reference it.

## A board reference that does not exist yet

A reference to a board with no file opens a blank board. The file is created by
the first drawing.
