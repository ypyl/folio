# Journal

A journal day is a page whose name is a date: `YYYY-MM-DD`, stored under
`journals/`. The calendar in the sidebar lists the days; the ones with a note are
marked.

> Demo guide. #Welcome has the table of contents.

## Today

The demo wrote a note for today, #[[{{today}}]], and for two earlier days. Click a
marked day in the calendar to open it, or press **Today** in the status bar. A
real vault opens today's note on load; the demo lands on #Welcome instead so you
can read this first.

## Days without notes

Every date is a journal day, whether or not it has a file. Open a day with no note
and you get a blank page; the file appears only when you type and the save lands.
Opening it writes nothing.

## What a day is for

A day is where the day's links land. Open #Reminders and then today's note to see
the app write two reminders into it.
