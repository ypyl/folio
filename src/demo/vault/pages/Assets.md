# Assets

Every file that is not a page, a journal day, or a board is an asset. Folio keeps
them in `assets/` and lists them in Files. A page can show an image or link to a
file with ordinary Markdown.

> Demo guide. #Welcome has the table of contents.

## An image from the vault

![Three panes reading one Markdown folder](assets/folio-flow.svg)

That image is a real file in the demo's `assets/` folder. Move the caret into the
line to see the Markdown, or click the image to expand it. The app reads the bytes
from the vault and shows them without copying the file anywhere.

## A plain file link

[The demo reading list](assets/reading-list.txt) is a text file. Activating the
link opens the file in a new tab. Other types open in the browser when it can show
them, and download otherwise.

## Adding your own

Drag a file into a page or paste a screenshot. Folio copies it into `assets/`,
gives it a unique name, and inserts the link at the drop point. Try it: drop an
image below this line.

## Links and files in the panel

The right panel lists this page's files alongside its page references. Clicking
one opens it.
